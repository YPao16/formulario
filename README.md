# Proyecto React con Vite

Proyecto inicial con React, Vite, Babel y Bootstrap.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

La configuración de Babel se encuentra en `vite.config.js`. Bootstrap se importa
desde `src/main.jsx`, incluyendo sus estilos y JavaScript.
